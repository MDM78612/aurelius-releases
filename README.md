# Aurelius Desktop Releases

Download the Aurelius desktop app and its updates from here.

This repository only hosts installers and update files. It contains no source code.

## Download

Get the latest installer from the [Releases](../../releases/latest) page:

| Platform | File |
| --- | --- |
| Windows (64-bit) | `Aurelius-Windows-<version>-Setup.exe` |
| macOS | `Aurelius-Mac-<version>-Installer.dmg` |
| Linux | `Aurelius-Linux-<version>.AppImage` |

Releases marked **Pre-release** are staging builds for testing and are not meant for general use.

You need an Aurelius account to sign in. If you don't have one, contact your administrator.

## Updates

The app checks for updates on its own and installs them when you quit. You don't need to come back here after the first install. To check by hand, use the update option in the app.

## First launch

The installers are not yet code-signed, so your system may warn you the first time:

- **Windows:** if SmartScreen appears, choose **More info**, then **Run anyway**.
- **macOS:** if the app is blocked, open **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Linux:** make the file executable (`chmod +x Aurelius-Linux-*.AppImage`), then run it.
